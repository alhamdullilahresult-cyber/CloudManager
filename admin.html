📖 API Documentation

Public Script Endpoint

https://your-domain.vercel.app/api/scripts/{id}

Returns the raw Lua code of an active script as text/plain; charset=utf-8.
Returns HTTP 404 if script not found or not active.
Rate limited to 60 requests/minute per IP.

ROBLOX LOADSTRING USAGE:
-- Simple one-liner
loadstring(game:HttpGet("https://your-domain.vercel.app/api/scripts/{id}"))()

-- Safe version with error handling
local url = "https://your-domain.vercel.app/api/scripts/{id}"
local ok, result = pcall(game.HttpGet, game, url)
if ok and result then
    local fn, err = loadstring(result)
    if fn then fn()
    else warn("[Boyfinity] Compile error:", err) end
else
    warn("[Boyfinity] Failed to fetch script")
end

Compatibility Notes

✅ game:HttpGet(url) — Standard Roblox executor API
✅ loadstring(code)() — Must be enabled by the executor
✅ CORS — All endpoints return Access-Control-Allow-Origin: *
✅ Cache-Control — Set to no-cache so updates are always fresh
⚠️ loadstring must be allowed by the executor. If blocked, the executor itself cannot execute it (not a limitation of this API).
